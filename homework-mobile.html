任务一 · 事件侦探观察记录

用手机打开课程页探针区，依次做 5 种操作，日志按真实触发顺序记录如下：

操作事件触发顺序（真实记录）
单击touchstart → touchend → click（位移小于阈值，几乎没有 touchmove）
向上拖动touchstart → 连续多次 touchmove → touchend → click，拖得越远 move 越多
向左快速滑touchstart → 密集 touchmove（十几到几十次）→ touchend → click
双指触摸第二根手指落下再触发一次 touchstart（touches.length 变 2）；先抬起的指头从 touches 消失、出现在 changedTouches 里，每根手指各触发一次 touchend
长按后抬起touchstart → 长按期间几乎没有 touchmove → touchend → click（间隔远超 300ms，不算双击）

验收三问：
① 一次拖动里 touchmove 的触发次数和滑动距离成正比——手指每移动一小段浏览器就采样触发一次，长距离拖动可达几十次，短击几乎没有。
② click 出现在 touchend 之后——它是系统在抬手后补发的，所以 touch 逻辑和 click 逻辑混用会「点一次执行两次」。
③ 把 touchend 换成 touchcancel 后，正常滑动不再触发回调——touchcancel 只在来电、通知横幅、系统手势打断时触发；反之若只监听 touchend 而不监听 touchcancel，被打断时状态会卡住。

加分 · 轨迹草图：快速横滑时各 touchmove 坐标的 y 值几乎不变、x 单调递减，连线近似一条水平直线；拐弯拖动时连线即为手指实际曲线路径。

核心代码 ① 滑动判定与冷却

// mx_ touchend 里用 changedTouches[0] 算横向位移，阈值 40px
function mx_onGestureEnd(mx_e) {
  var mx_dx = mx_e.changedTouches[0].clientX - mx_gStartX;
  if (Math.abs(mx_dx) < mx_gThreshold) { return; }  // 40px 内视为误触
  if (mx_dx < 0) {
    if (mx_gIndex >= mx_gDishes.length - 1) { mx_showTip('已经是最后一张'); return; }
    mx_gIndex++;
  } else {
    if (mx_gIndex <= 0) { mx_showTip('已经是第一张'); return; }
    mx_gIndex--;
  }
  mx_renderDish(mx_dx < 0 ? 1 : -1);
  mx_gLocked = true;                                // 300ms 冷却，防连滑跳两张
  setTimeout(function () { mx_gLocked = false; }, mx_gCooldown);
}

容器上写 touch-action: pan-y：横向手势由 JS 接管，纵向滚动交还浏览器，互不打架。

核心代码 ② 双指缩放「不跳」的关键

// mx_ 以两指中点 m 为基准缩放：压住的同一个内容点缩放前后位置不变
// 推导：c = (m - t) / s  →  t2 = m - (m - t) × (s2 / s)
function mx_zoomAt(mx_newScale, mx_px, mx_py) {
  var mx_ratio = mx_newScale / mx_zScale;
  mx_zTx = mx_px - (mx_px - mx_zTx) * mx_ratio;
  mx_zTy = mx_py - (mx_py - mx_zTy) * mx_ratio;
  mx_zScale = mx_newScale;
}

// mx_ 松手时把位移夹在图片边缘之内，1× 时最大位移为 0，拖不出去
function mx_clampZoom() {
  var mx_maxX = Math.max(0, (mx_zImg.offsetWidth * mx_zScale - mx_rect.width) / 2);
  mx_zTx = Math.min(mx_maxX, Math.max(-mx_maxX, mx_zTx));

}

核心代码 ③ 摇一摇判定与降级

function mx_onMotion(mx_e) {
  var mx_acc = mx_e.accelerationIncludingGravity;
  if (!mx_acc) { return; }
  // Chrome 无传感器也派发分量为 null 的空事件，必须拿到数值才算支持
  if (typeof mx_acc.x !== 'number' && typeof mx_acc.y !== 'number'
   && typeof mx_acc.z !== 'number') { return; }
  var mx_mag = Math.sqrt(mx_acc.x ** 2 + mx_acc.y ** 2 + mx_acc.z ** 2);
  if (mx_mag > 18) { mx_onShake(); }   // 超阈值 → 1.5s 冷却内抽菜谱
}
踩坑记录：第一次实现时「2 秒自动降级」不触发——排查发现 Chrome 在没有传感器的设备上仍会派发 devicemotion 事件，只是 accelerationIncludingGravity 的各分量是 null。原来的代码把「收到事件」当成了「有传感器」。修复：只有拿到数值分量才判定支持，复验通过。
