设计说明

iconfont 字体图标方式。一份 CSS 分发四个字符，通过 CSS ::before 注入到 DOM。优势是轻量、可继承字体颜色、可任意缩放；限制是图标字形必须提前生成、无法动态调整 stroke 属性。
